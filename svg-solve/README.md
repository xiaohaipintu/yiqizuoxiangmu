# SVG 拼图还原 · Auto Solver

`index.html` 单文件网页，双击即开（`file://` 可用，无依赖、不联网）。
载入**碎片**（切割工具导出的 ZIP / 多个 SVG）→ **自动拼回整图** → 导出拼好的 SVG。

```bash
start svg-solve\index.html
```

## 两种求解模式

| 模式 | 依据 | 效果 |
| --- | --- | --- |
| **坐标模式**（有 `viewBox` 原点时自动用） | 碎片文件自带原始坐标 | **零误差**，瞬时 |
| **纹理求解**（强制 / 无坐标时） | 完全不看坐标，只按拼接缝的颜色连续性找位置 | 横竖网格切割可靠；斜线/曲线切割只能部分还原 |

坐标模式是「作弊」但完全合法：`svg-cut` 导出的每块碎片，`viewBox` 就是它在原图中的位置。

## 用法

1. **载入**：拖入 ZIP 或一批 `.svg`（可多选），或点「示例：自动切 3×3 / 4×4 / 自由笔斜切」——示例会用 `../svg-cut/cut-engine.js` 现场切一张内建图。
2. **求解**：点「自动拼好」（或按 `S`）。模式 `自动` = 有坐标走坐标，没坐标走纹理。
3. **看结果**：底部显示 `n/m 块对位（最大偏差 x）`；没拼上的碎片排在主图下方「待拼」一排，不会乱放。
4. **导出**：`导出拼好的 SVG`，整图一个文件（每块是一个带 `viewBox` 的嵌套 `<svg>`）。

## 实现

纹理求解流程（`svg-solve/index.html` 里的 `solveTexture`）：

```
每块渲染成栅格(RGBA + mask + 边界像素表)
  → 两两求最优相对偏移：候选位置(四边贴合 / bbox 对齐 / 边界点投票)
      逐个算接缝代价 = 颜色差 + 缝隙罚 + 覆盖度罚，重叠则直接否决
  → 按分数排序，自适应阈值筛出「强边」
  → 强边建图 → 连通分量 → 主分量内 BFS 传播定位
  → 「中位数 + 内点平均」迭代（抗单条错边）
  → 残差一致性检查：与其他边矛盾的边踢掉重建（最多 4 轮）
  → 细精度重渲染 → 按 BFS 顺序逐块跟已定位邻居对齐（锚定式精修）
```

调通过的关键坑（都留了注释）：

- 边界像素**按奇数步长抽样**——偶数步长会系统性只采到左边/上边，右下边的接缝全漏（曾导致只对上 4/24 对）
- 颜色比较取**两侧各往内 1px 的实心像素**，避开抗锯齿边缘
- 接缝允许 1~2px 缝（切缝本身就有 kerf），缝越宽越扣分
- 重叠像素**直接否决**该候选（几何做硬约束，颜色只负责排序）
- 迭代重估时邻居表存的是「对方相对我」的偏移，**反解要减**（写错成加会让定位整体塌成 1/n）

## 已知边界

- 斜线 / 曲线切割的纹理求解还不稳（边界点投票候选已加，但分数区分度不够）——这类碎片请用坐标模式。
- 不处理**旋转**（切割工具不转碎片）；要处理旋转件需要额外的角度搜索。
- 碎片里若有外部引用（`<image href="http://…">`），栅格化会失败并给出提示。
- 同一页内联多块时 `id` 会重复；单块文件独立打开没问题（示例碎片已按块生成独立 `clipPath` id）。
