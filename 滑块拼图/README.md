# 滑块拼图（H5 小游戏）

纯前端单文件，双击 `index.html` 即可玩，不需要服务器、不依赖任何 CDN。

## 来源

这份代码**不在当前分支的工作区里**，是从 git 历史里取回来的：

| 提交 | 说明 |
| --- | --- |
| `81794f9` | feat: 实现滑块拼图（3/4/5 阶、图片模式、计时步数、最佳纪录、手机适配） |
| `b148f4d` | revert: 撤回本次会话的全部改动（拼图代码与部署配置不属于本项目） |

取回命令（内容与原提交逐字节一致）：

```bash
git show 81794f9:index.html      > 滑块拼图/index.html
git show 81794f9:tools/check.js  > 滑块拼图/tools/check.js
```

## 功能

- 3 / 4 / 5 阶滑块
- 图片模式（切成小块打乱后拼回去）
- 计时 + 步数统计
- 最佳纪录（存 `localStorage`）
- 手机适配

## 注意

`滑块拼图/` 与仓库里的 `拼图还原项目/` 是**两种不同的东西**：

- `滑块拼图/` —— 玩的小游戏，人手动拖动方块；
- `拼图还原项目/` —— 从一张「碎片散落的真实照片」自动还原成完整图形。

`tools/check.js` 是该提交附带的校验脚本，当前 `index.html` 并不引用它，保留只为存档。
