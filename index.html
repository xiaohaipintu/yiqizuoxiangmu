拼图项目 SVG Toolchain

三个纯前端单文件工具，双击即开、无需服务器和联网：生成一张图 → 按线切开 → 自动拼回。 每一步的产物都是标准 SVG，可以单独拿走用。

生成 → 切割 → 拼回，全链路可复现

01 · GENERATE

随机 SVG 生成器

10 种程序化风格（几何碎片 / 波浪 / 点阵 / 光斑 / 干涉环 / 孟菲斯 / 色块 / 极光 / 花瓣 / 条纹）。 种子可复现，元素密集、无大面积纯色（细线网 + 颗粒 + 碎点叠加），导出 SVG / PNG。

02 · CUT

SVG 线切割

自由笔：按住鼠标划一道就是一刀，松手立刻切。也支持竖线 / 横线 / 点选折线 / 网格。 每块导出为独立 SVG（viewBox 保留原图位置），可打包 ZIP + 刀模线。

03 · SOLVE

自动拼回

拖进碎片（ZIP 或多个 SVG）→ 自动拼成整图。 有坐标时零误差还原；无坐标时按拼接缝颜色连续性求解（网格切割 3×3 全对、4×4 14/16）。

另有一套面向真机拍摄的流水线在 拼图还原项目/（Python 抠像 + 拼图求解算法）， 与本网页工具链互不依赖。
网页工具链的目录：svg-gen/、svg-cut/、svg-solve/，各自的 README 里有用法与自测命令。
